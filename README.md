# Imst blüht auf – 3D-Stadtkarte

Interaktive 3D-Karte mit den Themen aus den Protokollen der Initiative „Imst blüht auf“.
Der Inhalt (`karte.bin`) ist verschlüsselt (AES-256-GCM) und wird erst nach der Anmeldung im Browser entschlüsselt.

Datenquellen: basemap.at, © OpenStreetMap-Mitwirkende, Land Tirol (data.tirol.gv.at), Mapzen/AWS Terrain Tiles, Kenney (CC0).
Erstellt von der IDC AI Unit.
